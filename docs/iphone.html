Padel sur iPhone

Installation du relevé des clubs Playtomic, Sport-finder et MATCHi. À faire une seule fois, environ 3 minutes.

1Installer Scriptable

Application gratuite, qui fait tourner de petits scripts sur l'iPhone.

Ouvrir Scriptable dans l'App Store

Installez-la, puis revenez sur cette page.

2Copier le script

Voir le script
Chargement…

3Coller le script dans Scriptable

  1. Ouvrez Scriptable et touchez + en haut à droite.
  2. Touchez la zone de texte vide, puis Coller.
  3. Touchez le titre Untitled Script tout en haut et remplacez-le par Padel, exactement.
  4. Touchez Done en haut à gauche.

4Premier lancement

  1. Dans Scriptable, touchez la vignette Padel.
  2. Le script demande votre clé GitHub : collez la clé Raccourci Padel (elle commence par github_pat_), puis Enregistrer. Elle est gardée dans le trousseau de l'iPhone et ne sera plus demandée.
  3. Laissez l'application ouverte environ 2 minutes : le script interroge les sites, envoie les réponses, puis attend la mise à jour de la page.
  4. À la fin, touchez Ouvrir la page.

Pour copier la clé sur l'iPhone : ouvrez-la dans les notes de l'ordinateur et envoyez-la-vous (AirDrop, Notes iCloud), ou collez-la depuis le presse-papiers partagé si l'iPhone et l'ordinateur sont sur le même compte Apple.

5Ensuite

Sur la page Padel Liège, le bouton Actualiser depuis l'iPhone lance ce script directement.
